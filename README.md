# cinebloc

This portfolio-grade application replicates the core streaming experience, featuring dynamic movie and TV show carousels, category filtering, a detailed media information screen, and a robust search engine. Designed to impress interviewers, the project strictly adheres to Clean Architecture principles and implements BLoC for professional, predictable state management. By utilizing live data instead of static mock files, the app showcases real posters, ratings, and overviews to deliver a truly authentic, production-level user experience.
